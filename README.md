# Лабораторная работа 9. Вложенные списки и таблицы

## Как запустить
1. Демонстрация: `python main.py`
2. Проверки: `python test_table.py`
3. Дополнительно (рекурсия): `python recursion_example.py`

---

## Структура файлов
- `table.py` — функции: `row_sums`, `column_sums`, `diagonal_pattern`, `transform`.
- `main.py` — ввод матрицы, вывод сумм, диагонального узора и результата преобразования.
- `test_table.py` — проверки через `assert`.
- `recursion_example.py` — рекурсивная и итеративная версии факториала.

---

## Проверки

### Суммы строк и столбцов
| Матрица | Суммы строк | Суммы столбцов |
|---|---|---|
| `[[1,2,3],[4,5,6]]` | `[6, 15]` | `[5, 7, 9]` |
| `[[7]]` | `[7]` | `[7]` |
| `[[1],[-1],[0]]` | `[1, -1, 0]` | `[0]` |
| `[]` | `[]` | `[]` |

### Диагональный узор
`diagonal_pattern(3)` →
0 1 1
2 0 1
2 2 0

text
`diagonal_pattern(1)` → `[[0]]`.

### Вариант 1 (отрицательные → 0)
| Исходная | Ожидаемый результат | Факт |
|---|---|---|
| `[[-2, 0, 3], [4, -5, 6]]` | `[[0, 0, 3], [4, 0, 6]]` | Совпадает |
| `[]` | `[]` | Совпадает |

После вызова `transform`:
- исходная матрица **не изменилась**;
- изменение `result[0][0]` не влияет на исходную.

### Дополнительно: рекурсия
- `factorial(0) == 1`, `factorial(5) == 120`.
- Для n = 0..20 рекурсивная версия совпадает с итеративной.
- Трассировка `factorial(3)`: 3 → 2 → 1 → 0 → 1 → 1 → 2 → 6.
